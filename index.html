    建立 Apps Script 專案

    開啟 Apps Script
  2. 2
    貼上單一 Code.gs

    刪除編輯器內原有內容，貼上完整程式碼並儲存。不需要建立 HTML 或資訊清單檔案。

  3. 3
    執行 setup()，再部署

    上方函式選單選 setup 並按「執行」，同意 Google 授權。首次使用選「部署 → 新增部署 → 網頁應用程式」；更新過程式碼則選「管理部署作業 → 編輯 → 新版本 → 部署」。執行身分選「存取網頁應用程式的使用者」，再複製結尾為 /exec 的網址。

  4. 4
    貼上網址並驗證

    按下後會另開 Google 授權分頁；完成後直接回到拾記，系統會自動連接並更新狀態，不必再按一次。
